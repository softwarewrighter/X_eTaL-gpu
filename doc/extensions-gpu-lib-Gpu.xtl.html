libraryextensions/gpu/lib/Gpu.xtl

Gpu: XIR programs run on OpenCL devices (or the reference interpreter) from X_eTaL

Import: "gp:" u_se< "Gpu" Run with xetal-x (X_eTaL-extensions' bridge host): "scripts/xx run prog.xtl" puts this package and this repository's libraries in reach.

The first half binds the native functions (extensions/gpu/rust), one line each, with X_eTaL-extensions' binding macro (Ffi.xtlm): a session per thread, loaded, bound, run, read. The second half is ordinary X_eTaL over them: functions that write XIR programs (the text is data, so these are functions, not macros: docs/macros-and-extensions.md, X4), a product and a dense layer in one call each, and a check for f32 results.
