librarylibs/Accel/src/Accel.xtl

Accel: the acceleratable subset of X_eTaL: elementwise arithmetic, masks, reductions, products, a layer

Import it with an alias of your choice: "ac:" u_se< "Accel". Put libs/Accel/src on XETAL_PATH ("just path"); the reference is libs/Accel/docs.

Every function here is one whole-array expression in the subset a GPU (or an FPGA) can take on directly: static scalar types, pure functions, arithmetic and comparisons item by item with scalar extension, a select by mask, reductions, inner products and tables. No recursion, no nested arrays, no input or output. The X_eTaL evaluator is the reference: X_eTaL-gpu runs the same functions on a GPU and must give the same answers (the demos are the programs it checks). Names with l: are exported; the others are private.
