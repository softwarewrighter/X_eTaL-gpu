macro libraryextensions/gpu/lib/Gpu.xtlm

Gpu.xtlm: the accelerate macro: a function's text handed to the GPU runner

Import it with the facade: "gp:" u_se< "Gpu" brings Gpu.xtl (the functions) and this file (the macro) under one alias. The program must import the facade as gp:, since the expansion calls gp:l_ower, gp:b_ind, gp:r_un and gp:o_utput.

u:f_ := KINDS gp:a_ccel< "{ x w -> ... }" defines a function of the same parameters that hands the text to the gpu extension, which lowers it through X_eTaL's own crates for the arguments' shapes when they are bound (once per set of shapes), runs it on opencl:0 with the arguments uploaded, and reads the result back. KINDS says how each argument is taken, "float" or "int" per parameter ("" for all Floats); an Int array must be bound as int to be looked up by. The function is one or two named arrays to one array, written on one line without quotes; its libraries are the ones the calling file imports (the expansion names the file, so the runner reads its u_se< lines). The same macro, with a runner that has load-from-source, bind and run, would accelerate on anything.
