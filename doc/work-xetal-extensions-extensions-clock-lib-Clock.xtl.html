Clock.xtl -- the facade of the clock extension: wall-clock and monotonic time, which X_eTaL does not have, for timestamps and timing. Import: "ck:" u_se< "Clock" Run with xetal-x (xetal-x --ext DIR puts this directory on XETAL_PATH). Each signature line is written out by the binding macro (lib/Ffi.xtlm).
