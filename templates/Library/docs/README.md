# __NAME__

__SUMMARY__

```
"__ALIAS__" u_se< "__NAME__"
```

Put each library's `src/` directory on `XETAL_PATH` (`just path`
prints them; see the [README](../../../README.md)); `__ALIAS__` is the
recommended alias.

## Functions

| Function | Type | What |
| -------- | ---- | ---- |
| `__ALIAS__i_dentity x` | `a -> a` | the value itself |

## Examples

From `../tests/basics.xtl`:

```
      __ALIAS__i_dentity 1 2 3
1 2 3
```
